# Stocked

¿Tienes todo lo que necesitas para cocinar esta semana?

## Objetivo

Reducir en un 30% el desperdicio de alimentos por compras duplicadas o mal calculadas, gestionando en un solo lugar el banco de recetas, el inventario de despensa y el calendario semanal, calculando automáticamente los ingredientes que faltan comprar.

## Stack

| Capa | Tecnología |
|---|---|
| Backend | .NET Core 8 / C# + Entity Framework Core |
| Frontend | Angular 18 |
| Auth | JWT |
| Docs API | Swagger / OpenAPI |
| Despliegue | Azure App Service (backend) + Azure Static Web Apps (frontend) |
